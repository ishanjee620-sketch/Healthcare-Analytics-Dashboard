# Healthcare Analytics Dashboard 📊

## Project Overview

A beginner-level Power BI dashboard created to analyze healthcare data related to patients, appointments, and medicines.

## Tools Used

- Power BI
- Power Query
- DAX
- Excel

## Dashboard Insights

- Total Patients
- Total Appointments
- Completed Appointments
- Pending Appointments
- Patients by Gender
- Patients by Department
- Appointments Over Time
- Appointment Status
- Medicines by Category

## Dataset

The project contains three tables:

- Patients
- Appointments
- Medicines

## Skills Demonstrated

- Data Cleaning
- Data Modeling
- DAX Measures
- Data Visualization
- Interactive Slicers
- Dashboard Design
